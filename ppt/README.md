# NovaCPP Master Presentation Deck

This directory contains the complete 10-slide presentation deck for **NovaCPP: High-Performance Full-Stack C++ Web Framework & Agentic AI Engine (v3.0.0)**.

Each slide is stored as an independent, modular markdown document structured with:
- **Slide Metadata**: Timing, category, and slide number.
- **Visual & Structural Slide Content**: Headlines, bullet points, architecture diagrams, benchmark dashboards, and comparison tables.
- **Comprehensive Presenter Notes**: Speaking points and talking guides to deliver a cohesive, persuasive pitch covering the entire project.

## How to Present or Export

### Option A: Markdown Slide Tools (Marp / Slidev)
The files use standard Markdown headings and fenced ASCII diagrams that render out of the box in tools like **Marp** or **Slidev**:
```bash
# Using Marp CLI to compile to PDF or PPTX
npx @marp-team/marp-cli@latest ppt/*.md -o presentation.pdf
npx @marp-team/marp-cli@latest ppt/*.md -o presentation.pptx
```

### Option B: Direct Presentation in Markdown Viewer
Open any file in your editor (VS Code, Cursor, Antigravity) with Markdown Preview enabled. Each slide includes structured layout blocks and dedicated presenter notes at the bottom.

### Option C: Copying into PowerPoint / Google Slides
The text has been divided into slide titles, key bullets, comparison tables, and dashboard metrics so that each section can be copied directly into slide text boxes.
